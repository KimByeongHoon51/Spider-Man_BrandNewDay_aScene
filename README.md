# Spider-Man_BrandNewDay_aScene

영화 「스파이더맨: 브랜 뉴 데이」의 한 장면 — 긴 복도에서 헐크가 스파이더맨을 쫓는 장면을 오마주한 팬 메이드 웹게임 (비상업).

▶ 플레이: https://kimbyeonghoon51.github.io/Spider-Man_BrandNewDay_aScene/

## 규칙
- 육각형 복도의 6개 면을 오가며 80초(100m) 동안 헐크에게서 도망치면 클리어. 헐크에게 따라잡히면 게임 오버
- **스파이더 센스**: 면이 붉게 깜빡이면 1초 뒤 돌 무더기, 파랗게 깜빡이면 2초 뒤 아이템
- 돌에 부딪히면 1초 기절
- 수류탄은 먹으면 그 자리에 설치 → 헐크가 밟으면 폭발
  - 거미줄 수류탄: 헐크 속도 50% 감소(2초) / 전기 수류탄: 헐크 1초 기절
- 페이즈 4개(거리 기준). 4페이즈 진입 시 헐크의 박수치기(필중, 3초 기절)

## 조작
- ← → : 육각형을 따라 옆 면으로 점프 (같은 방향 6번 = 한 바퀴) / ↑ ↓ : 맞은편 면으로 덤블링 (모바일: 스와이프)
- M 음소거, P·Esc 일시정지

## 밸런스
타이틀의 "밸런스 설정"에서 헐크 속도 등 수치를 바꿀 수 있어요(브라우저에 저장).
주소 뒤에 `#hulkSpeed=1.5` 처럼 붙여도 됩니다. 테스트용: `#god` `#start=75` `#bot` `#sim=초`

## 제작
- 단일 `index.html` (Canvas 2D, 외부 라이브러리 없음), 효과음·배경음은 Web Audio로 합성
- Spider-Man, Hulk는 Marvel의 캐릭터입니다. 이 게임은 비상업 팬 오마주입니다.
