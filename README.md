# Spider-Man_BrandNewDay_aScene

영화 「스파이더맨: 브랜드 뉴 데이」에서 헐크가 좁은 복도로 스파이더맨을 쫓는 장면을 오마주한 웹 게임 (팬 메이드, 비상업)

▶ **플레이:** https://kimbyeonghoon51.github.io/Spider-Man_BrandNewDay_aScene/

---

## 1. 기획 의도

「스파이더맨: 브랜드 뉴 데이」에서 헐크와 스파이더맨의 전투 장면은 영화에서 가장 역동적인 액션이었습니다. 그중에서도 **좁은 복도에서 헐크가 스파이더맨을 뒤쫓는 장면**이 가장 인상 깊었고, 이 장면을 오마주한 게임을 만들어 보고 싶었습니다.

목표는 영화 속 장면을 게임으로 옮기는 것이었습니다.

- 영화에 나오는 **거미줄 수류탄**과 **전기 수류탄**으로 헐크의 움직임을 둔화시키는 모습
- 헐크가 **박수치기**로 스파이더맨을 튕겨 내는 모습
- 달려오는 스파이더맨을 정면에서 잡는 영화의 **카메라 연출** — 스파이더맨 뒤로 헐크가 점점 다가오는 구도를 그대로 담으려고 했습니다.

## 2. 게임 개요

| 항목 | 내용 |
|---|---|
| 장르 | 정면 시점 추격 러너 |
| 플레이 시간 | 약 80초 (총 거리 100m) |
| 목표 | 헐크에게 잡히지 않고 복도 끝까지 달리기 |
| 플랫폼 | 웹 브라우저 (PC 키보드, 모바일 스와이프) |
| 아트 | 카툰풍 (코믹스 효과 글자·말풍선) |

## 3. 핵심 규칙

- **육각형 복도**: 복도 단면이 육각형이고, 스파이더맨은 바닥·벽·천장 6개 면을 모두 달릴 수 있습니다.
- **추격**: 스파이더맨은 헐크보다 20m 앞에서 출발합니다. 헐크가 더 빨라서 그냥 달리기만 하면 결국 잡힙니다. 체력은 없고, **잡히면 바로 게임 오버**입니다.
- **스파이더 센스**: 면이 깜빡이며 2초 뒤에 무엇이 오는지 미리 알려 줍니다.
  - 🔴 붉게 깜빡 → 돌 무더기 (부딪히면 1초 기절, 그사이 헐크가 따라옴)
  - 🔵 파랗게 깜빡 → 수류탄 아이템
- **수류탄**: 먹으면 그 자리에 설치되고, 뒤따라오는 헐크가 밟으면 터집니다. 헐크는 덩치가 커서 6개 면을 모두 차지하므로 설치된 수류탄은 반드시 밟습니다.
- **거리 표시 없음**: 헐크와의 거리는 숫자 대신 **화면 속 헐크의 크기**로 보여 줍니다. 가까워질수록 스파이더맨 바로 뒤에서 화면을 가득 채웁니다.

## 4. 조작

| 키 | 동작 |
|---|---|
| ← → | 육각형을 따라 옆 면으로 점프 (같은 방향 6번 = 한 바퀴) |
| ↑ ↓ | 맞은편 면으로 덤블링 |
| 모바일 | 좌우·위아래 스와이프 |
| ? 버튼 / H | 조작법 |
| P / Esc | 일시정지 · M 음소거 |

점프(0.3초)와 덤블링(0.3초) 중에는 공중이라 돌을 피하지만 아이템도 먹을 수 없습니다.

## 5. 레벨 구성 (거리 기준 4페이즈)

| 페이즈 | 구간 | 돌이 나오는 면 | 돌 주기 | 아이템 |
|---|---|---|---|---|
| 1 | 20 ~ 40m | 2면 | 5초 | 5초마다 1개 (1번째 거미줄, 2번째 전기, 이후 랜덤) |
| 2 | 40 ~ 60m | 2면 | 2.5초 | 5초마다 랜덤 1개 |
| 3 | 60 ~ 80m | 3면 | 2.5초 | 5초마다 랜덤 1개 |
| 4 | 80 ~ 100m | 4면 | 2.5초 | 5초마다 랜덤 1개 + **헐크의 박수치기** |

- 아이템은 돌이 없는 면에만 나옵니다.
- 결승점(100m)에 도착하는 돌과 아이템은 나오지 않습니다.

## 6. 아이템

| 아이템 | 효과 | 연출 |
|---|---|---|
| 거미줄 수류탄 | 헐크 속도 50% 감소 (2초) | 흰 거미줄 그물이 퍼지고 헐크 몸에 거미줄이 감김 · SPLAT! |
| 전기 수류탄 | 헐크 1초 기절 | 민트색 번개가 원형으로 퍼지고 헐크 몸에 전기가 튐 · SHOCK! |

먹는 순간 스파이더맨이 "HAND GRENADE!"를 외칩니다.

## 7. 헐크의 박수치기 (4페이즈 진입 시 1회)

1. 헐크가 **"RAAAARGH!"** 하고 포효합니다. 박수치기의 전조입니다 (2초).
2. 제자리에서 팔을 크게 벌리며 **"HULK SMASH!"** — 6개 면이 모두 붉게 깜빡입니다 (1초).
3. 손이 맞닿는 순간 충격파가 퍼지고, 스파이더맨은 **3초 기절**합니다. 피할 수 없는 기믹입니다.

## 8. 연출

- **카메라**: 원본 장면처럼 스파이더맨 정면에 고정했습니다. 스파이더맨은 화면 쪽으로 달려오고, 헐크는 복도 안쪽에서 쫓아옵니다.
- **시작**: 벽에 금이 가고 → 스파이더맨이 벽을 뚫고 날아와 착지 → 헐크가 벽을 부수며 "HULK SMASH!" → 스파이더맨 "RUN!"
- **게임 오버**: 헐크가 한 손으로 스파이더맨을 붙잡아 들어 올린 뒤 바닥에 내리꽂습니다 → GAME OVER
- **엔딩**: 복도 끝에서 스파이더맨이 돌아서 쇼커 건틀릿을 장착하고 "BRUCE, I'M SORRY!" → 헐크 턱에 어퍼컷 "WHAM!" → CLEAR!
- **긴장감**: 헐크가 7m 안으로 오면 화면 가장자리가 붉게 맥박치고, 헐크의 발소리가 거리에 따라 커집니다.

## 9. 밸런스

| 항목 | 값 |
|---|---|
| 스파이더맨 속도 | 1 m/s |
| 헐크 속도 | 1.35 m/s |
| 시작 거리 차 | 20 m |
| 돌 충돌 기절 | 1초 |
| 거미줄 감속 | 50%, 2초 |
| 전기 기절 | 1초 |
| 박수치기 | 준비 1초, 기절 3초 |

- 처음 기획은 헐크 2m/s였지만, 시뮬레이션해 보니 **아이템을 모두 먹고 돌을 하나도 맞지 않아도 약 32초에 잡혀서** 1.35m/s로 낮췄습니다. 자동 플레이 기준으로 결승점에서 헐크와 약 6~8m 차이가 납니다.
- 주소 뒤에 `#balance`를 붙이면 밸런스 설정 창이 열려서 수치를 바꿔 볼 수 있습니다. 바꾼 값은 그 브라우저에만 저장됩니다.

## 10. 제작하며 바뀐 점

- **좌우 조작**: 화면 기준 좌우 → 위·아래 면을 구분하는 방식 → 최종적으로 **육각형을 따라 회전하는 방식**(6번 = 한 바퀴)으로 정했습니다.
- **방향 안내 화살표**: 천장에서 좌우가 반대로 느껴지는 문제를 보완하려고 넣어 봤지만, 난이도가 너무 쉬워져서 뺐습니다.
- **돌 예고**: 처음에는 1초 전이었지만, 돌이 보이자마자 도착해 예고가 의미 없어서 아이템과 같은 2초로 늘렸습니다.
- **박수치기**: 헐크를 클로즈업했더니 돌진처럼 보여서, 제자리 박수로 바꾸고 전조는 대사로만 주었습니다.

## 11. 제작 정보

- `index.html`: 게임 본체 (Canvas 2D, 외부 라이브러리 없음)
- `sounds.js`: 효과음 6종 — 거미줄·전기 수류탄 폭발, HULK 음성, 박수, 돌 충돌, 스파이더 센스
- `BGM.mp3`: 플레이 중 배경음 (타이틀·결과 화면에서는 나오지 않음)
- 그 밖의 효과음은 Web Audio로 합성
- 테스트용 주소: `#god`(무적) `#start=75`(시작 위치) `#bot`(자동 플레이) `#sim=초`(빨리 감기)
